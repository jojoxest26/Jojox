# Sicurezza di JoJoX

JoJoX è uno strumento di sicurezza: se trovi un problema di sicurezza che riguarda JoJoX stesso (il sito, il server di analisi, la GitHub App, l'estensione VS Code o il server MCP), vogliamo saperlo il prima possibile.

## Come segnalare una vulnerabilità

Scrivi a **jojoxest26@gmail.com** con oggetto che inizia con `[Sicurezza]`. Descrivi il problema, i passaggi per riprodurlo e, se possibile, il suo impatto potenziale.

Non aprire una issue pubblica per una vulnerabilità non ancora risolta.

## Cosa puoi aspettarti

- conferma di ricezione entro 5 giorni lavorativi
- una valutazione iniziale della gravità appena possibile
- aggiornamenti periodici finché il problema non è risolto
- un avviso quando la correzione è stata rilasciata

## Ambito

In ambito: sito jojox.it, server di analisi, GitHub App, estensione VS Code, server MCP.

Fuori ambito: i servizi di terze parti che usiamo (Supabase, Stripe, Railway, Vercel, GitHub) — vanno segnalati direttamente a loro.

## Programma di ricompense

Essendo un progetto autofinanziato da una sola persona, non offriamo ricompense in denaro oggi. Offriamo una risposta rapida e onesta, e un ringraziamento pubblico se lo desideri.
